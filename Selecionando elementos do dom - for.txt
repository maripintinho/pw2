Selecionando elementos do dom - formas de pegar <> e guardar em variáveis
existem 5 modos de acesso aos elementos do dom:
- por Tag (marca) -> const header = document.getElementsByTagName("div")[0] //primeira div que aparece [0, 1, 2, 3..]
- por ID -> const P1 = document.getElementById("texto") //<p id = "texto">01</p>
- por nome -> document.getElementsByName("cidade")[índice] //<input name="cidade"></>
- por classe -> getElementsByClassName("footer")[índice] //<div class="footer"></>
- por Seletor -> id: document.querySelector('#texto') ; classe: document.querySelector('.texto') 
                     document.querySelectorAll()

Eventos - são basicamente um conjunto de ações que são realizadas em um determinado elemento da página web, seja ele um texto, uma imagem ou uma div, exemplo.
Muitas das interações do usuário que está visitando sua página com o conteúdo do seu site podem ser consideradas eventos. ex passar cursor em cima de algo, fechar aba:
click, mouseout, mouseup, mouseenter, mousemove, mousedown, focus, keypress, load
