Bootstrap 5: guia completo de consulta

Um manual prático para reconhecer classes, montar componentes, adaptar layouts e entender as interações que podem aparecer na prova.

Exemplos de códigoTabelas de classesErros frequentes
Como usar: procure uma classe na busca, consulte o exemplo e adapte os nomes, IDs e conteúdos ao enunciado. Os exemplos usam Bootstrap 5.3.

1. Estrutura inicial do HTML

Todo documento começa com a estrutura HTML. O CSS do Bootstrap estiliza os elementos; o JavaScript habilita componentes interativos como modal, navbar recolhível e carrossel.

<!DOCTYPE html>
<html lang="pt-br">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha página</title>

  <!-- Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
        rel="stylesheet">
</head>
<body>

  <h1 class="text-primary">Olá, mundo!</h1>

  <!-- Bootstrap JS: antes de fechar o body -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
Não confunda: CSS = aparência; JavaScript = comportamento; viewport = adaptação a telas diferentes. O arquivo bootstrap.bundle.min.js já inclui o Popper.

2. Sistema de grid e responsividade

O grid do Bootstrap divide a linha em 12 colunas. Normalmente, a estrutura é container → row → col.

123456789101112

Exemplo: duas colunas de metade da largura cada.

<div class="container">
  <div class="row">
    <div class="col-md-6">Coluna 1</div>
    <div class="col-md-6">Coluna 2</div>
  </div>
</div>
ClasseO que faz
containerConteúdo centralizado com largura responsiva.
container-fluidOcupa toda a largura disponível.
rowCria uma linha do grid.
colColuna automática.
col-66 de 12 colunas em qualquer tamanho de tela.
col-md-66 colunas a partir do breakpoint md; abaixo disso, ocupa a largura toda.
col-lg-44 colunas a partir de lg.
g-3Espaçamento entre colunas e linhas.
g-0Remove o espaçamento do grid.

Breakpoints

PrefixoLargura mínimaUso típico
sm576 pxCelulares grandes
md768 pxTablets
lg992 pxNotebooks e desktops
xl1200 pxTelas grandes
xxl1400 pxTelas muito grandes
<!-- Celular: largura inteira; md: metade; lg: um terço -->
<div class="col-12 col-md-6 col-lg-4">Conteúdo</div>
A soma das colunas de uma linha costuma ser 12. Ex.: três cards com col-md-4 (4 + 4 + 4 = 12).

3. Flexbox e alinhamento

ClasseFunção
d-flexAtiva Flexbox.
flex-rowOrganiza em linha.
flex-columnOrganiza em coluna.
flex-wrapPermite quebra para outra linha.
justify-content-startDistribui no início do eixo principal.
justify-content-centerCentraliza no eixo principal.
justify-content-endAlinha ao final do eixo principal.
justify-content-betweenEspaço entre os elementos.
justify-content-aroundEspaço igual em ambos os lados de cada item.

align-items-endAlinha no final do eixo transversal.
<div class="d-flex justify-content-between align-items-center">
  <h2>Título</h2>
  <button class="btn btn-primary">Entrar</button>
</div>

Com justify-content você distribui no eixo principal; com align-items, alinha no eixo transversal.

4. Margens e espaçamento interno

O padrão é {propriedade}{direção}-{tamanho}.

Propriedade: m = margin (fora); p = padding (dentro).

Direção: t = topo; b = baixo; s = início; e = final; x = horizontal; y = vertical. Sem direção, aplica em todos os lados.

ClasseSignificado
mt-3Margem superior.
mb-4Margem inferior.
ms-2Margem no início horizontal (esquerda em idiomas LTR, como o português; direita em RTL).
me-2Margem no final.
mx-autoMargens horizontais automáticas; útil para centralizar elemento com largura definida.
my-5Margens verticais.
p-3Padding em todos os lados.
px-4Padding horizontal.
py-2Padding vertical.
pt-3 / pb-3Padding superior / inferior.

Escala padrão: 0 = 0; 1 = 0,25rem; 2 = 0,5rem; 3 = 1rem; 4 = 1,5rem; 5 = 3rem. O valor em pixels depende do tamanho-base da fonte.

<section class="container mt-5 p-4">
  <h2 class="mb-3">Título</h2>
  <p class="px-2">Texto com padding horizontal.</p>
</section>

7. Navbar — barra de navegação

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">Minha marca</a>

    <button class="navbar-toggler" type="button"
      data-bs-toggle="collapse" data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>

    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item">
          <a class="nav-link active" href="#">Início</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#sobre">Sobre</a>
        </li>
      </ul>
    </div>
  </div>
</nav>

navbar-expand-lg mantém os links expandidos a partir de telas grandes; abaixo do breakpoint lg, o menu fica recolhido e pode ser aberto pelo botão. O botão e o conteúdo precisam apontar para o mesmo ID.

Erro comum: escrever navbar-expand-1g com o número 1. O correto é navbar-expand-lg com a letra L minúscula.

9. Cards

<div class="card h-100">
  <img src="imagem.jpg" class="card-img-top" alt="Descrição">
  <div class="card-body">
    <h5 class="card-title">Título do card</h5>
    <p class="card-text">Descrição do conteúdo.</p>
    <a href="#" class="btn btn-primary">Saiba mais</a>
  </div>
  <div class="card-footer">Informação adicional</div>
</div>

card é o contêiner; card-img-top posiciona a imagem no topo; card-body envolve o conteúdo; card-title e card-text formatam título e texto; card-footer cria o rodapé. Use h-100 para cards com altura igual dentro da linha.

Três cards em uma linha

<div class="row g-3">
  <div class="col-md-4">...card 1...</div>
  <div class="col-md-4">...card 2...</div>
  <div class="col-md-4">...card 3...</div>
</div>

10. Carrossel

<div id="meuCarousel" class="carousel slide" data-bs-ride="carousel">
  <div class="carousel-indicators">
    <button type="button" data-bs-target="#meuCarousel"
      data-bs-slide-to="0" class="active" aria-current="true"></button>
    <button type="button" data-bs-target="#meuCarousel"
      data-bs-slide-to="1"></button>
  </div>

  <div class="carousel-inner">
    <div class="carousel-item active">
      <img src="imagem1.jpg" class="d-block w-100" alt="Imagem 1">
    </div>
    <div class="carousel-item">
      <img src="imagem2.jpg" class="d-block w-100" alt="Imagem 2">
    </div>
  </div>

  <button class="carousel-control-prev" type="button"
    data-bs-target="#meuCarousel" data-bs-slide="prev">
    <span class="carousel-control-prev-icon"></span>
  </button>
  <button class="carousel-control-next" type="button"
    data-bs-target="#meuCarousel" data-bs-slide="next">
    <span class="carousel-control-next-icon"></span>
  </button>
</div>

O primeiro slide deve ter active. Cada indicador usa data-bs-slide-to com índice começando em zero. Os controles usam prev e next.

Se as imagens tiverem proporções diferentes, podem parecer ter alturas diferentes. Para padronizar: class="d-block w-100" com style="height: 400px; object-fit: cover;". cover preenche o espaço e pode cortar um pouco da imagem sem distorcê-la.

<div class="alert alert-warning" role="alert">Atenção!</div>

<!-- Alerta que pode ser fechado -->
<div class="alert alert-warning alert-dismissible fade show" role="alert">
  Confira os dados.
  <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
</div>

<!-- Badge -->

alert cria o componente; alert-success, alert-danger, alert-warning e alert-info definem a variação. alert-dismissible permite fechar; data-bs-dismiss="alert" faz o botão dispensar o alerta.

14. Modal

Uma janela sobreposta ao conteúdo da página. O botão pode abrir o modal usando atributos Bootstrap ou JavaScript.

<!-- Botão para abrir -->
<button class="btn btn-primary" data-bs-toggle="modal"
  data-bs-target="#meuModal">Abrir modal</button>

<!-- Modal -->
<div class="modal fade" id="meuModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Confirmação</h5>
        <button type="button" class="btn-close"
          data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Conteúdo do modal.</div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary"
          data-bs-dismiss="modal">Fechar</button>
      </div>
    </div>
  </div>
</div>

Partes: modal (componente), modal-dialog (caixa), modal-content (conteúdo), modal-header, modal-title, modal-body e modal-footer.

15. Accordion

<div class="accordion" id="perguntas">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button" type="button"
        data-bs-toggle="collapse" data-bs-target="#resposta1">
        Primeira pergunta
      </button>
    </h2>
    <div id="resposta1" class="accordion-collapse collapse show"
      data-bs-parent="#perguntas">
      <div class="accordion-body">Resposta da pergunta.</div>
    </div>
  </div>
</div>

O accordion organiza painéis que abrem e fecham. show faz o painel começar aberto. data-bs-parent pode fazer com que apenas um painel do grupo fique aberto por vez.

<div class="progress" role="progressbar"
  aria-label="Progresso" aria-valuenow="70"
  aria-valuemin="0" aria-valuemax="100">

17. Imagens

<img src="imagem.jpg" class="img-fluid" alt="Descrição">
<img src="imagem.jpg" class="rounded" alt="Bordas arredondadas">
<img src="imagem.jpg" class="rounded-circle" alt="Circular">
<img src="imagem.jpg" class="img-thumbnail" alt="Miniatura">

img-fluid limita a imagem à largura do contêiner e mantém a proporção. rounded arredonda bordas; rounded-circle aplica border-radius: 50% (vira círculo perfeito apenas em imagens quadradas 1:1; se for retangular, vira oval/elipse); img-thumbnail aplica aparência de miniatura.

18. JavaScript básico usado com Bootstrap

Selecionar elementos

const formulario = document.getElementById("meuFormulario");
const botao = document.querySelector(".btn-primary");
const campos = document.querySelectorAll(".form-control");

getElementById procura um ID; querySelector retorna o primeiro elemento que corresponde ao seletor CSS; querySelectorAll retorna todos os correspondentes.

Evento de clique e envio

botao.addEventListener("click", function() {
  alert("Botão clicado!");
});

formulario.addEventListener("submit", function(evento) {
  evento.preventDefault(); // impede o envio/recarregamento padrão
  alert("Formulário enviado!");
});

Limpar formulário

formulario.reset();

Abrir e fechar modal pelo JavaScript

const elementoModal = document.getElementById("meuModal");
const modal = new bootstrap.Modal(elementoModal);

modal.show(); // abre
modal.hide(); // fecha

Alterar conteúdo e estilo

document.getElementById("titulo").textContent = "Novo título";
document.getElementById("titulo").classList.add("text-danger"); // ou .style.color = "red"
Ordem importante: carregue o Bootstrap JS antes do seu script que usa bootstrap.Modal. Colocar os scripts perto do fim do body é uma prática comum.

20. Erros comuns e como conferir

  • Classe digitada incorretamente: navbar-expand-1g não existe; use navbar-expand-lg (letra L).
  • ID e destino diferentes: data-bs-target="#menu" exige um elemento com id="menu".
  • Esquecer o active no primeiro slide: o carrossel precisa de um item inicial visível.
  • Esquecer o JavaScript: navbar recolhível, modal, carrossel e dropdown precisam do Bootstrap JS.
  • Esquecer row ou container: o grid deve ser estruturado corretamente.
  • Somar colunas errado: três colunas col-md-4 ocupam 12; quatro colunas col-md-4 passam para outra linha.
  • Label sem associação: for="email" deve corresponder a id="email".
  • Radio com name diferente: opções que pertencem ao mesmo grupo precisam compartilhar o mesmo name.
  • Usar classe errada no campo: inputs normalmente usam form-control; selects usam form-select.
  • Imagem com tamanho desigual: w-100 define largura, mas não padroniza altura. Para isso, use altura definida e object-fit: cover.
  • Colocar script antes do Bootstrap: seu JavaScript pode tentar usar um componente antes de a biblioteca carregar.
